## About

AnimePanda helps people find their next anime. The landing page shows titles by category, and a filter narrows them by genre, year and more. Title data comes from the MyAnimeList API, which gave us a solid catalog to work from.

The centerpiece is a panda chatbot built on the OpenAI API. You chat with it or set your filters, and it recommends titles that match. The recommendations come back as swipeable cards: like or pass on each one, and save the ones you want to a list for later.

Rails handles the backend: REST endpoints and server-rendered pages with HTML, CSS and JavaScript. The team made 370+ commits.
